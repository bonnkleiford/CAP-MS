   # Instances

   - `orlib/`: the original OR-Library files cap44.txt, cap84.txt, cap114.txt (Beasley 1990).
   - `CAP44/`, `CAP84/`, `CAP114/`: facilities.csv (fixed costs), customers.csv (demands), unit_cost.csv (unit transport costs), and `disruptions/` with the train20, train50 and test20 path files for every horizon and disruption level.

   See the main README for the file formats.
